PRO TIP #4 • LOSS-FREE LOG ESCAPE HATCH

Zoom into compacted test logs via the Airlock Blob Vault

CLAUDE.md / Agent Rules Snippet (1-Click Copy) 
# Whole Body Compute (`body`) Power-User Rules
- **Commits & Checkpoints**: Prefer `body commit` (or `body commit <paths> -m "..."`) instead of multi-turn `git status` + `git diff` + `git add` + `git commit` loops. Before risky refactors, run `body checkpoint <label>`.
- **Read Code Natively (Zero-RAM AST Shield)**: Call native `Read` / `read_file` directly on source files instead of `cat`/`head`/`sed` shell loops. The `<3ms` Blood-Brain Barrier hook automatically slices oversized files with `0 GB` local LLM RAM.
- **Compacted Logs (`[BLOB:<id>]`)**: When a test or CLI log shows `[BLOB:<id>]`, recover exact lines locally via `body bbb --blob <id> --lines START:END` instead of re-running the full test suite.
- **Live macOS Apps & Logged-In Chrome (macOS)**: Prefer `body eyes --app "..."` and `body hands --app "..." --no-cursor` over full-screen screenshots (`screencapture`) or AppleScript.
05 • Troubleshooting & FAQ

Quick answers when something feels off.

Why didn’t body eyes see elements inside Chrome or Electron?

Install the unified notarized helper once via body eyes --install-app and enable Whole Body Compute.app under System Settings → Privacy & Security → Accessibility. Your Terminal and IDE need zero TCC permissions.

Pressing Fn opens the macOS Emoji picker instead of body ears

Run body ears --status to check for conflicts. Either set System Settings → Keyboard → Press 🌐 key to: Do Nothing, or pick a custom chord such as body ears --hotkey opt+space.

How do I check if hooks are actually active in my repo?

Run body shield --status to verify Claude Code, Antigravity, Cursor, and Codex hook wiring, then run body bbb --window 1h --tools to inspect live tool interceptions.

My Mac feels warm or low on Unified RAM with local models loaded

Run body heart to inspect thermal state and swap pressure, then run body perfusion --evict to evict idle 14B-70B local weights back to Darwin’s Inactive File Cache in <50ms.
