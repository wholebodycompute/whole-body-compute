2. Frequently Asked Security Questions

Q1: "Isn't granting macOS Accessibility effectively granting GUI-session root?"

Yes - at the macOS OS level, kTCCServiceAccessibility is one of the highest-privilege TCC entitlements on macOS, and treating it lightly is a mistake. Apple's TCC framework does not scope Accessibility to a single target window.

  • Strictly Optional: Leave Accessibility OFF unless you actively want an agent to inspect or drive live macOS GUI apps via body eyes / body hands.
  • Deterministic Vault, Origin & Field Blindfolds: Even when enabled, body eyes hard-blocks DOM extraction on password managers (1Password, Bitwarden, Apple Passwords, LastPass, KeePassXC, Keychain Access, Dashlane, NordPass, Authy, YubiKey), returning [BLOCKED_SECURE_VAULT] with zero elements. Browser tabs on web vaults or root IAM consoles (my.1password.com, vault.bitwarden.com, console.aws.amazon.com/iam) return [BLOCKED_SENSITIVE_ORIGIN]. Any AXSecureTextField is masked to [REDACTED_PASSWORD] before serialization.
  • Engine-Level Actuation Denylists & GUI-Terminal Guards: FovealVisionEngine (actuate, click_element, click_xy, type_text, paste_element, attach_file, trigger_menu_item, dispatch_hotkey), ax_act, and PalWorkflow reject clicks/keystrokes into password vaults, macOS System Settings / SecurityAgent TCC dialogs, OS partition/account tools (Disk Utility, GParted, Users & Groups), anti-bot CAPTCHA surfaces (reCAPTCHA, hCaptcha, Turnstile), sensitive web vault origins, or AXSecureTextField password fields - and block GUI keystroke/paste smuggling of sudo rm -rf, .bashrc persistence, or live vendor secrets into Terminal windows.

Q2: "How is body eyes safer than screenshot-based Computer Use agents?"

Screenshot-loop agents upload full-screen PNGs every 1-2 seconds to cloud vision APIs - leaking Slack banners, .env terminal splits, and password toasts as raw pixels before any redactor can touch them. By contrast, body eyes parses structured AXUIElement nodes locally in <15ms with zero screenshots, scrubs 23+ secret vendor formats (sk-, ghp_, AKIA, ya29., DB URIs, Base64 tokens, SSNs, cards) in <1ms, and neutralizes DOM prompt-injection breakouts (including invisible Plane-14 Unicode Tags, Base64/Hex/Binary/Caesar smuggling, and #-wrapped multi-line comments) via EpithelialScreenFilter before any token reaches an LLM.

Q3: "If I grant Accessibility to my Terminal or IDE, doesn't every child process inherit it?"

Yes - which is why Whole Body Compute isolates kTCCServiceAccessibility and kTCCServiceMicrophone inside one unified notarized app: Whole Body Compute.app (com.wholebodycompute.app, Team ID Y25SHBA3P5). macOS TCC attributes permissions to the responsible parent application bundle (e.g. Terminal.app or Cursor.app). Granting Accessibility to a general-purpose terminal would expose it to untrusted child scripts.

  • Zero Terminal / IDE / Python TCC: Whole Body Compute.app is a zero-Python Swift menu-bar broker (LSUIElement) signed with Hardened Runtime and Library Validation ON (zero third-party or Python dylibs). Grant Accessibility once to Whole Body Compute.app - never to your terminal or IDE.
  • Authenticated IPC (foveal.sock): ~/.whole_body_compute/foveal.sock and its per-session foveal.token are locked to 0600 inside a 0700 directory, capped at 64 KiB, and gated by kernel LOCAL_PEERPID + LOCAL_PEERCRED UID checks, HMAC-SHA256 (op_bind + 30s replay window), and SecCodeCopyGuestWithAttributes.
  • Native Swift Blindfolds & 1-Click Kill Switches: PrivacyBlindfold.swift redacts vaults, System Settings / SecurityAgent, sensitive web origins, and AXSecureTextField inside Swift prior to IPC. Option-click the menu-bar icon to pause all organs in 1 click (or toggle Eyes & Hands and Ears independently).
  • Verified Install: body eyes --install-app (pinned SHA-256 + Team ID Y25SHBA3P5 verification) or brew install --cask wholebodycompute/tap/whole-body-compute.

Q4: "Does WBC watch my clipboard or send code/screen data to external servers?"

  • Zero Code, Zero Prompts, Zero Screen Data in Telemetry: Whole Body Compute never transmits source code, file paths, repo names, prompts, clipboard text, window titles, screen pixels, or IP addresses ("$ip": null). Inspect the exact payload anytime with body telemetry show or opt out via body telemetry disable / DO_NOT_TRACK=1. See TELEMETRY.md.
  • Concealed Pasteboard Respect: Clipboard items carrying password-manager autofill markers (org.nspasteboard.ConcealedType, org.nspasteboard.TransientType, org.nspasteboard.AutoGeneratedType, com.agilebits.onepassword) are dropped before NSPasteboardTypeString is ever read - even when copied from a browser extension inside Chrome. Set WBC_AMBIENT_DISCOVERY=0 to disable passive motif discovery entirely.
